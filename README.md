# Taller IV - Programación Web (UCA, Ciclo 02, 2026)

Proyecto con dos partes:

- `backend/`: API REST con Express (endpoints `/api/health` y `/api/info`)
- `frontend/`: Vite + React + reactstrap

## Cómo correrlo

Necesitas Node 20.19+ o 22.12+ y **dos terminales**.

```bash
# Terminal 1 - Backend (http://localhost:3000)
cd backend
npm install
npm run dev

# Terminal 2 - Frontend (http://localhost:5173)
cd frontend
npm install
npm run dev
```

Abre http://localhost:5173 en el navegador.

Si `npm install` del frontend da un error de dependencias (ERESOLVE), usa:
`npm install --legacy-peer-deps`
